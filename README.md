# Reality Glitch — The Silent Room

A mobile-friendly, single-file mystery escape-room game prototype.

## Play locally
Open `index.html` in a modern web browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `reality-glitch`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. Your site URL will appear in the Pages section.

This is a static HTML game and does not require a backend server.
